# Markdown with Mermaid

Preview **Markdown**, render diagrams offline and export your document.

## Features

| Feature | Ready |
| --- | --- |
| Automatic Markdown preview | Yes |
| Source-scroll synchronization | Yes |
| Formatted copy and HTML / PDF / DOCX | Yes |

## From source to document

```mermaid
flowchart LR
    A[Markdown source] --> B[Live preview]
    B --> C[Mermaid diagrams]
    C --> D[Copy or export]
```

Select a fragment for **formatted copy** or export the whole document.
