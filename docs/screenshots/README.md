# Preview samples

These images were captured from the real WebView2 integration host on Windows 10
during local 1.4.0 validation. They show the preview panel, not a completed native
Notepad++ acceptance test. The English and Russian samples contain the same
feature table and diagram structure. Their source files are
`preview-sample.en.md` and `preview-sample.ru.md`.

- `preview-light.en.png` / `preview-dark.en.png`: English content and diagram
  labels, used by the English README.
- `preview-light.png` / `preview-dark.png`: the equivalent Russian content, used
  by the Russian README to demonstrate Unicode rendering.
- `preview-selection.png`: the English sample with a rendered selection. It
  illustrates selection in the preview; export correctness is tested separately.

All screenshots use the current Preview assets, including the filename-copy
button. They are actual WebView2 captures; no labels are painted onto the images.

The files contain project-authored test content and no personal paths or documents.
