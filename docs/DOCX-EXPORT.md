# Экспорт DOCX

Нажмите **DOCX ↓** справа от PDF и выберите файл. Подсказка кнопки —
**Export to DOCX**; у соседних кнопок — **Export to HTML** и **Export to PDF**.
Значок DOCX выполнен в том же контурном стиле. Альтернативный путь:
**Plugins → Markdown_with_Mermaid → Export DOCX...**.

Экспортируется весь текущий буфер, включая несохранённые изменения.
Снимок фиксируется до диалога сохранения: переключение вкладки или изменение
текста во время экспорта не меняет создаваемый документ. Масштаб и тема основного
предпросмотра сохраняются.

С версии 1.3.0 выделение ограничивает экспорт. В Preview сохраняются выбранный
текст и его структура, включая частично выделенные абзацы, списки и таблицы;
пересечённая выделением Mermaid-схема включается целиком. Изображения снимка
встраиваются из кэша Preview без повторной загрузки. Если последняя рабочая область
— редактор, экспортируется его выделенный Markdown как отдельный документ.
Кнопка DOCX не сбрасывает выбранную область; щелчок в тексте Preview переключает
область на Preview. Без выделения сохраняется весь буфер. Цвета выбранной готовой
Mermaid-схемы сохраняются; оформление текста Word остаётся стандартным.

## Содержимое документа

- Обычный текст, заголовки Word 1–6, жирный, курсив, зачёркивание, моноширинный текст.
- Маркированные и нумерованные списки, вложенные списки, статические флажки задач.
- Редактируемые таблицы с повторяемой строкой заголовков.
- Внешние и локальные ссылки; ссылки на заголовки текущего файла через закладки Word.
- Mermaid как встроенный SVG с растровым PNG для совместимости с редакторами.
- Изображения Markdown как встроенный PNG; для PNG/JPEG/GIF/BMP/WebP/SVG
  дополнительные файлы рядом с DOCX не нужны. Анимация становится статичной.
- Ошибка Mermaid сохраняется сообщением и исходником; остальные схемы экспортируются.
  Недоступное изображение заменяется предупреждением.

Документ формируется из очищенного HTML после завершения Mermaid. Это обычный
OOXML с текстом и таблицами, без HTML altChunk, макросов и исполняемых вложений.
Для совместимости SVG содержит вычисленные цвета, шрифты и обводки.

## Автономность и размер

Используется MIT-библиотека **docx 9.12.0** из официального npm-пакета:
`assets/docx.iife.js`, 1 366 532 байта. Она поставляется вместе с плагином,
загружается только в отдельном скрытом WebView2 при экспорте DOCX и не требует
Office, LibreOffice, Pandoc, Node.js или интернет-соединения. Существующий
WebView2 Runtime остаётся общим требованием плагина. Лицензия включена в поставку.

Схемы Mermaid 11.16.1 строятся автономно. Успешно загруженные изображения
предпросмотра сохраняются в памяти через WebView2 WebResourceResponseReceived /
GetContent. DOCX получает именно эти байты, без повторного HTTP-запроса и без CORS.
Снимок сохраняет изображения при переключении вкладки и изменении буфера.
Скрытая страница DOCX не загружает картинки из сети: CSP разрешает только data URI.

Если изображения ещё нет в кэше предпросмотра, плагин использует фоновый WinHTTP
или чтение локального файла. Для HTTP поддерживаются перенаправления и системный
прокси; cookies, автоматическая аутентификация и отключение проверки TLS не используются.
Ссылки источников изображений вида github.com/owner/repo/blob/ref/path преобразуются
в raw.githubusercontent.com; адреса самих гиперссылок остаются прежними.
Такой резервный сетевой путь требует интернета, но не разрешения CORS.
Отсутствующий локальный файл не разыскивается в других папках и не подменяется
похожим изображением. Предупреждение содержит причину: файл не найден, HTTP-код,
HTML вместо картинки, превышение лимита или ошибка сети. Атрибуты width/height
исходного изображения учитываются при размещении в DOCX.

## Оформление и ограничения

Страница Letter, книжная ориентация, поля 0,7 дюйма, Arial 11 pt, код Consolas 9 pt.
Тема светлая, масштаб экспорта фиксирован. Крупные рисунки уменьшаются до страницы.
Длинные блоки кода разбиваются по строкам; таблицы — по строкам таблицы.
Сверхвысокая строка таблицы и сложный произвольный HTML могут потребовать правки
в редакторе Word. CSS не переносится целиком, расположение страниц может отличаться
от PDF. Формулы, встроенные видео, сложная HTML-вёрстка и стили расширений VS Code
не преобразуются в специальные объекты Word. Код сохраняется моноширинным текстом.

Лимиты: 256 изображений, один файл изображения до 16 МиБ,
результат до 128 МиБ, экспорт до 180 секунд. Параллельно выполняется один DOCX.
Кэш текущего документа — до 64 МиБ закодированных данных; при переходе к другому
документу кэш обновляется, а уже начатый экспорт сохраняет собственный снимок.
Резервная HTTP-загрузка ограничена пятью перенаправлениями и тайм-аутами.
Данные передаются из WebView2 небольшими порциями с подтверждением записи.
Сначала создаётся временный файл рядом с назначением; готовый DOCX заменяет
назначение только после успешной записи. Если файл заблокирован другой программой,
его прежняя версия остаётся на месте. Временные файлы удаляются при завершении
и при штатном закрытии Notepad++.

## Проверка

Интеграционные тесты используют настоящий WebView2 для x64 и x86: шесть типов
Mermaid, кириллица, локальное изображение, ошибочная схема, 120 строк таблицы,
260 строк кода, несохранённый буфер, сохранение темы/масштаба, заблокированный файл,
недоступная папка и отмена при закрытии. `tests/check-docx.py` проверяет ZIP/XML,
изображения, ссылки, закладки и редактируемые элементы восьми DOCX.
Для проверки страниц разработчик использует локально распакованный LibreOffice;
он не входит в поставку и не нужен пользователю для экспорта.

Дополнительные тесты: HTTP-сервер без CORS и с Cache-Control: no-store,
изображение, доступное только при первом GET, редирект, 404, HTML-страница,
превышение размера, цикл редиректов и отмена фоновой загрузки. Проверяется,
что изображение с единственным разрешённым GET остаётся в DOCX после изменения
буфера, а сервер не получает повторного запроса. tests/check-docx-images.py
проверяет изображения, размеры, причины ошибок и счётчики запросов.
