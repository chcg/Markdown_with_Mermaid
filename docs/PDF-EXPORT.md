# Экспорт PDF — Markdown_with_Mermaid

Реализован 18 октября 2026 года через WebView2 `ICoreWebView2_7::PrintToPdf`.
Кнопка **PDF ↓** стоит сразу после **HTML ↓**. В меню плагина есть
**Export PDF...**. Выберите имя файла в стандартном диалоге сохранения;
при работе кнопка блокируется, после завершения внизу документа появляется
путь или сообщение об ошибке.

В 1.1.1 исправлено разбиение длинных блоков кода: стиль `inline-block`,
унаследованный из VS Code, создавал в Chromium пустую страницу перед длинным
деревом каталогов. В печатном режиме `pre` и `code` теперь обычные блоки с
разрешённым разбиением между страницами. Предпросмотр использует прежние стили.

В версии 1.2.2 исправлены размеры обычных изображений. Общий CSS `height: auto`
перекрывал HTML-атрибут `height="150"`, поэтому логотип Mermaid занимал ширину
страницы. Теперь заданные `width`/`height` учитываются до печати; при ограничении
ширины размеры уменьшаются пропорционально. Высота 150 CSS px соответствует
112,5 pt в PDF, как и физический размер изображения в DOCX.

## Что экспортируется

Весь текущий буфер Markdown, включая несохранённые изменения. Снимок создаётся
до диалога сохранения, поэтому последующее переключение вкладок или изменение
текста не меняет уже начатый экспорт.

С версии 1.3.0 при выделении экспортируется только выбранная часть. В Preview
это снимок отрендеренного фрагмента с сохранёнными абзацами, ссылками, списками,
таблицами и SVG-схемами. Изображения выбранного фрагмента берутся из кэша Preview
и встраиваются без повторной загрузки; недоступные заменяются текстовым пояснением.
Если последняя рабочая область — редактор, выделенный исходный Markdown рендерится
как отдельный документ. Нажатие PDF в панели не сбрасывает этот выбор; переход
к тексту Preview переключает область выделения. Без выделения печатается весь буфер.

Mermaid 11.16.1 строится автономно в отдельном скрытом контроллере WebView2.
Экспорт ждёт окончания рендеринга, загрузки шрифтов и изображений. Успешные
схемы переносятся из Shadow DOM в печатную страницу как SVG; исходники этих
схем и интерфейс панели не печатаются. Ошибочная схема сохраняется с сообщением
и исходником, остальные схемы продолжают строиться.

PDF использует A4, книжную ориентацию, поля 15 мм, масштаб 100%, светлую тему,
без колонтитулов браузера. Фоновые цвета печатаются. Масштаб, тема, позиция
прокрутки и содержимое основного предпросмотра не меняются из-за экспорта.
Готовые SVG в выделении Preview сохраняют цвета показанной схемы.

В PDF остаётся текстовый слой, в том числе кириллица. Длинный код переносится,
таблицы делятся между страницами с повторением шапки и без разрыва строк.
Схемы уменьшаются до доступной ширины и высоты страницы.

## Зависимости и обработка ошибок

Дополнительных библиотек, PDF-принтера, Office, Node.js и Pandoc у пользователя
не требуется. Используется тот же Microsoft Edge WebView2 Runtime, что и для
предпросмотра. Если Runtime не предоставляет API печати, плагин сообщает о
необходимости обновления. WebView2 SDK уже был включён в инструменты сборки.

Вначале создаётся временный PDF рядом с выбранным файлом. Только после успеха
он переименовывается с заменой результата. Ошибка печати или занятый файл
не уничтожает предыдущую версию. Одновременно выполняется один экспорт.
При завершении Notepad++ операция отменяется, временные файлы удаляются.
Общий тайм-аут — 120 секунд; ожидание отдельных изображений — до 15 секунд.
Недоступная картинка заменяется предупреждением внутри PDF и учитывается
в сообщении о сохранении. Сетевые изображения требуют доступа к их адресам.

## Проверка

`test.ps1` / `test.ps1 -Architecture x86` запускают общий C++-код плагина
в настоящем WebView2 с моделью сообщений Notepad++/Scintilla. Проверяются:

- PDF с шестью типами Mermaid: flowchart, sequence, ER, class, Gantt, pie;
- снимок буфера при изменении текущего документа во время экспорта;
- одинаковый PDF при 204% / тёмном preview и 50% / светлом preview;
- локальное SVG-изображение, кириллица, длинный код, неправильная схема;
- таблица со 120 строками, добавленными только в несохранённый буфер;
- занятый существующий PDF, недоступная папка и повторный запрос;
- отмена при завершении с очисткой временных файлов.

Прогон версии 1.1.0: **59 проверок x64 и 59 проверок x86, ALL TESTS PASSED**.
Бинарные проверки подтвердили архитектуру и шесть экспортов API Notepad++;
новых зависимостей от .NET или VC++ Redistributable нет.
Размер ZIP вырос примерно на 12 КБ относительно сохранённых ZIP 1.0.1.
Отдельной PDF-библиотеки в дистрибутиве нет; точные размеры архивов записаны
в `docs/research/pdf-package-sizes.json` рабочего проекта.

`tests/check-pdf.py` проверяет шесть PDF двух архитектур: размер A4,
текстовый слой, все строки таблицы, векторную геометрию и совпадение координат
текста при разных настройках preview. Это вспомогательный тест разработчика
с Python, pypdf и pdfplumber; эти программы не нужны пользователю плагина.
Проверочные PDF находятся в `build/previews`, изображения страниц —
в `build/pdf-qa`. Восемь страниц x64 просмотрены после рендеринга Poppler:
обрезания, наложения текста и пустых страниц на этих примерах не обнаружено.

Регрессия 1.1.1 дополнительно проверяет 160 строк обычного кода и 100 строк
подсвеченного JavaScript: сохранение каждой строки и отсутствие пустых страниц.
Для повторного экспорта конкретного Markdown можно передать
`test.ps1 -PdfRegressionMarkdown 'путь к файлу.md'`.
Проверка 1.1.1: по 62 PASS для x64 и x86 с файлом
`05-merlay-ARCHITECTURE.md`. Новый PDF содержит 6 страниц, пустых страниц нет.
Все 6 страниц документа и 6 страниц теста длинного кода просмотрены после
рендеринга Poppler. Машинные результаты — `docs/research/pdf-pagination-validation.json`.

Ограничения первой версии: нет выбора размера бумаги, ориентации и диапазона
страниц; очень широкие схемы уменьшаются и могут иметь мелкие подписи.
Произвольные сложные документы могут требовать дополнительной настройки
печатных стилей. DOCX, Copy и история переходов остаются в плане.

API: [печать WebView2](https://learn.microsoft.com/en-us/microsoft-edge/webview2/how-to/print),
[PrintToPdf](https://learn.microsoft.com/en-us/microsoft-edge/webview2/reference/win32/icorewebview2_7#printtopdf).
