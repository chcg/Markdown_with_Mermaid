# Markdown View

Просмотр **Markdown** по клавише **F3** в Total Commander.

## Возможности

Обычный текст, *курсив*, **полужирный**, ~~перечёркнутый~~ и `код`.

| Элемент | Результат |
| --- | --- |
| Заголовки и списки | ✓ |
| Таблицы и код | ✓ |
| Русский текст | ✓ |

```javascript
function preview(file) {
  return `Markdown View: ${file}`;
}
```

> Оформление основано на Markdown Preview из VS Code.

- [x] Собранная HTML-страница
- [x] Подсветка синтаксиса
- [ ] Следующая задача
